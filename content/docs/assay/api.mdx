Import from `@0xbuff/assay`. The package root is the supported import path. All functions except `collectObservations` are synchronous. Inputs to validation and integrity functions are accepted as unknown and checked at runtime.

## Evaluation

| Function | Return | Behavior |
| --- | --- | --- |
| `evaluate(definition, evidence, references?)` | EvaluationResponse | Verify inputs, compare criteria and compose required outcomes. |
| `inspectEvidenceCoverage(definition, evidence)` | ValidationResult of EvidenceCoverage | List missing and incomplete required criteria without evaluating them. |
| `projectPublicResult(definition, result)` | PublicProjectionResponse | Validate a full result and create its public projection. |

`EvaluationResponse` is either a complete result or an invalid-input failure. Inspect `outcome` before accessing findings. See [outcomes](/docs/assay/outcomes).

## Definition integrity

| Function | Return | Behavior |
| --- | --- | --- |
| `computeDefinitionDigest(draft)` | ValidationResult of string | Validate an unsigned draft and compute its digest. |
| `createAssessmentDefinition(draft)` | ValidationResult of AssessmentDefinition | Validate, derive the digest and seal the definition. |
| `verifyAssessmentDefinition(definition)` | ValidationResult of AssessmentDefinition | Verify structure and content digest. |

## Evidence and reference integrity

| Function | Return | Behavior |
| --- | --- | --- |
| `createEvidenceBundle(definition, draft)` | ValidationResult of EvidenceBundle | Verify the definition, bind observations and derive the evidence digest. |
| `verifyEvidenceBundle(definition, evidence)` | ValidationResult of EvidenceBundle | Verify evidence digest, coverage and definition lineage. |
| `createReferenceRecord(draft)` | ValidationResult of ReferenceRecord | Validate and seal a typed reference value. |
| `verifyReferenceBundle(definition, bundle)` | ValidationResult of ReferenceBundle | Verify every supplied record against its authorized definition. |

## Structural parsing

These functions check closed record shapes and resource limits. Structural parsing does not recompute the record's digest or authenticate its source.

| Function | Successful value |
| --- | --- |
| `parseAssessmentDefinitionDraft(input)` | AssessmentDefinitionDraft |
| `parseAssessmentDefinition(input)` | AssessmentDefinition |
| `parseEvidenceBundle(input)` | EvidenceBundle |
| `parseObservationPortReport(input)` | ObservationPortReport |
| `parseEvaluationResult(input)` | EvaluationResult |
| `decodeSerializedRecord(input)` | Bounded immutable JSON object; duplicate keys rejected |

The first five return ValidationResult of their corresponding type. The decoder returns SerializedRecordResult.

## Observation collection

`collectObservations(definition, evidence, port, options?)` returns a Promise of ObservationCollectionResult. Supply an optional signal in `options.signal`. The host implements the port. See [collection guide](/docs/assay/observation-ports).

## Return wrappers


```ts
type ValidationResult<T> =
  | Readonly<{ ok: true; value: T }>
  | Readonly<{
      ok: false;
      domain: ValidationDomain;
      diagnostics: readonly ValidationDiagnostic[];
    }>;
```

The serialized decoder uses the same success shape but its failure has diagnostics without a domain. Projection returns an opaque failure with `reasonCode` instead of diagnostics. Collection returns evidence and receipt directly on success and has distinct failure variants.

Always check `ok` before reading `value` or `evidence`.
