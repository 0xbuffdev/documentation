These pages describe the public release [v0.0.1](https://github.com/0xbuffdev/assay/releases/tag/v0.0.1), not unreleased work on main. The package ships TypeScript declarations and has no runtime dependencies.

## Reproducibility

Pin the package version and preserve your lockfile. Persist the authorized definition and evidence records with their digests, protected references when used, and evaluator identity. The package version identifies the distribution; the evaluator version identifies the supported finding semantics.

## Unsupported records

Older development schemas and policy identifiers are rejected. There is no runtime migration or automatic upgrade. Do not relabel or rehash an older record as schema 4. Preserve historical records and use the version that originally produced them, or create a newly authorized definition and evidence under the current contract.

See the [changelog](https://github.com/0xbuffdev/assay/blob/v0.0.1/CHANGELOG.md) and [release policy](https://github.com/0xbuffdev/assay/blob/v0.0.1/docs/releasing.md) for changes and release procedures.
