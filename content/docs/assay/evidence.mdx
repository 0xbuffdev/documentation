---
title: "Supply evidence"
description: "Create immutable evidence bundles and handle missing, truncated and artifact-scoped observations."
---

Use `createEvidenceBundle(definition, draft)` to bind observations to the exact definition. The draft accepts `schemaVersion`, `observations` and optional `artifactDigest`. Assay derives the definition lineage and evidence digest.

## Observation fields

Every observation has a criterion ID, unique evidence reference, kind and completeness. The value fields depend on the kind. See [record reference](/docs/assay/contracts).

For a text criterion named output:

```ts
const prepared = createEvidenceBundle(definition, {
  schemaVersion: 4,
  observations: [{
    criterionId: "output",
    evidenceRef: "capture-1",
    kind: "text",
    completeness: "complete",
    value: "ok",
  }],
});
```

This fragment assumes you imported the creator and sealed a matching definition. A successful result exposes `prepared.value`. Handle failure before using it.

## Missing and incomplete evidence

Omit observations for unavailable facts. Mark partial captures as truncated. Do not substitute a fabricated empty string or zero. Use `inspectEvidenceCoverage(definition, evidence)` to list missing and incomplete required criteria; it performs no comparison and does not account for alternative group outcomes.

## Bind evidence to an artifact

Set an explicit bundle artifact digest when associating evidence with an artifact. Every observation in a scoped bundle must declare an origin. An artifact origin carries the exact bundle digest and a source reference; an independent origin has a source reference but no artifact digest. Unscoped observations may omit origin, but cannot claim artifact scope.

Selected execution observations also require run reference and termination. See [execution facts](/docs/assay/execution-facts).

## Verify and correct

Use `verifyEvidenceBundle(definition, evidence)` to recompute the digest and check lineage. Create a new sealed bundle for corrections rather than editing existing records. Keep the original bundle if you need an audit history.

Assay validates consistency of the claims; your application must verify the actual source and artifact.
