---
title: "Collect observations"
description: "Inject an optional host-owned adapter to collect eligible missing public facts."
---

Use `collectObservations` when your application can obtain observations through an adapter. The collector is asynchronous; the evaluator remains synchronous and does not require a port.

## Implement a port

The adapter implements `observe(request, signal?)` and returns a report. This example uses a fixture to show the contract without installing a runner or connecting a service.

```js
// assay-docs: runnable
import {
  collectObservations,
  createAssessmentDefinition,
  createEvidenceBundle,
  evaluate,
} from "@0xbuff/assay";

const created = createAssessmentDefinition({
  schemaVersion: 4,
  assessmentId: "public-demo",
  revision: "rev1",
  policyVersion: "composed-required-v1",
  composition: {
    rootGroupId: "root",
    groups: [{ id: "root", operator: "all", children: [{ kind: "criterion", id: "stdout" }] }],
  },
  criteria: [
    {
      id: "stdout",
      kind: "exact_text",
      mode: "required",
      visibility: "public",
      parameters: { expected: { type: "literal", value: "ok" } },
    },
  ],
});
if (!created.ok) throw new Error("Invalid authored definition");
const definition = created.value;

const prepared = createEvidenceBundle(definition, {
  schemaVersion: 4,
  observations: [],
});
if (!prepared.ok) throw new Error("Invalid evidence");
const startingEvidence = prepared.value;

const mockPort = {
  async observe(request) {
    // request lists only public IDs, expected fact kinds and resource limits.
    return {
      schemaVersion: 4,
      definition: request.definition,
      provenance: {
        adapterId: "fixture",
        adapterVersion: "v1",
        runRef: "local-run",
        toolchainId: "node",
        toolchainVersion: "v24",
        capturedStdoutBytes: 2,
        capturedStderrBytes: 0,
        stdoutTruncated: false,
        stderrTruncated: false,
      },
      observations: [
        {
          criterionId: "stdout",
          evidenceRef: "stdout1",
          kind: "text",
          completeness: "complete",
          value: "ok",
        },
      ],
    };
  },
};

const collected = await collectObservations(definition, startingEvidence, mockPort);

if (!collected.ok) throw new Error("Collection failed");
const result = evaluate(definition, collected.evidence);
if (result.outcome !== "pass") throw new Error("Expected pass");
console.log(result.outcome);
```

Expected output: `pass`.

## Request and report

The request contains schema version, definition lineage, optional artifact digest, capture limits and eligible missing public criterion IDs with their observation kinds. Units, item types, execution selectors or public assertion IDs are included when applicable. Expected values, reference IDs, restricted criteria and commands are never sent.

The report echoes the definition identity and artifact scope, includes provenance and returns only requested observations. The provenance includes adapter and toolchain IDs and versions, run reference, captured stdout/stderr byte counts and both truncation flags. Their combined byte count is limited to 65,536.

Report observations cannot include their own origins. For selected execution facts, echo the selector and provide a top-level termination state. The collector attaches the report scope to new observations and seals the combined bundle.

## Handle the response

| Response | Meaning |
| --- | --- |
| ok: true | Sealed evidence and receipt; receipt is null if no port was invoked. |
| invalid_definition | Definition failed validation or integrity verification. |
| invalid_evidence | Evidence, report or combined lineage was invalid. |
| OBSERVATION_PORT_ERROR | Adapter rejected or threw. |
| OBSERVATION_CANCELLED | Host cancellation occurred. |

Existing observations retain their content and origin. The receipt identifies newly returned evidence references and the new digest. An empty report is legal but cannot satisfy a missing requirement.

## Cancel acquisition


```ts
const controller = new AbortController();
const pending = collectObservations(definition, evidence, port, {
  signal: controller.signal,
});
// Your application decides when to cancel:
controller.abort();
const collected = await pending;
```

This fragment assumes valid records and a port. The signal is passed to the adapter. Valid pre-aborted input does not invoke it; cancellation during acquisition ignores late completion. No default timeout or retries are applied. Your application must terminate any actual running process.

See the [record reference](/docs/assay/contracts) and [trust model](/docs/assay/security). The adapter is a source of claims, not a trusted execution service by virtue of its interface.
