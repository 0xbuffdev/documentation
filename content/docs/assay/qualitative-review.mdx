---
title: "Record qualitative reviews"
description: "Attach artifact-bound advisory feedback from a human or model without changing binding outcomes."
---

Qualitative reviews record attributed feedback about an artifact. They can support a host-owned review workflow, but cannot establish a required pass or fail. Use manual evidence for work that requires a separate authorized decision.

## Declare a review criterion


```ts
{
  id: "readability",
  kind: "qualitative_review",
  mode: "advisory",
  visibility: "public",
  parameters: {
    reviewPolicyId: "code-review",
    reviewPolicyVersion: "v1",
  },
}
```

Keep this criterion outside the required composition tree.

## Supply a review

The bundle must have an explicit artifact digest. The review's artifact origin must use that same digest and the policy fields must match the criterion.

```ts
{
  criterionId: "readability",
  evidenceRef: "review-1",
  kind: "qualitative_review",
  completeness: "complete",
  origin: {
    kind: "artifact",
    artifactDigest,
    sourceRef: "review-service",
  },
  reviewPolicyId: "code-review",
  reviewPolicyVersion: "v1",
  reviewer: {
    kind: "human",
    reviewerId: "reviewer-1",
    reviewerVersion: "v1",
  },
  uncertainty: "low",
  feedback: "Name the intermediate result before returning it.",
  citations: [{ artifactRef: "solution", startByte: 0, endByte: 10 }],
}
```

This fragment assumes `artifactDigest` is the host-computed digest of the reviewed artifact. Citation ranges are byte offsets with an exclusive end; verify them against the actual artifact.

For a model reviewer, use this reviewer object:

```ts
reviewer: {
  kind: "model",
  providerId: "provider",
  modelId: "review-model",
  modelVersion: "v1",
  promptId: "code-review",
  promptVersion: "v1",
}
```

Assay does not connect to a model provider. Your application obtains feedback, verifies provenance and supplies the observation. The optional observation port neither requests nor accepts qualitative review records.

## Limits and outcomes

Feedback must be nonempty inert text, at most 4,096 UTF-16 code units and UTF-8 bytes. Supply one to eight distinct citations with safe nonnegative byte offsets and start less than end. Uncertainty must be low, medium, high or unknown. Version identifiers cannot be the moving label latest.

Absent, truncated and complete reviews all remain inconclusive, with reasons `EVIDENCE_MISSING`, `EVIDENCE_TRUNCATED` and `REVIEW_REQUIRED` respectively. Advisory unresolved findings do not affect the binding outcome.

Review text, citations, attribution and uncertainty remain privileged evidence. [Public projection](/docs/assay/public-results) never copies them. Your application authorizes any separate disclosure.
