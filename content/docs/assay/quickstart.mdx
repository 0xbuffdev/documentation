---
title: "Evaluate your first result"
description: "Create a definition, seal a measurement and evaluate it with Assay."
---

This tutorial checks whether a measurement falls within an inclusive voltage range. You will create a criterion, provide the observed value and read the result.

## Prerequisites

Complete [installation](/docs/assay/installation). Use a file named `calibration.mjs` in your project.

## Create and evaluate an assessment

Copy the following example into the file. The measurement is a local fixture supplied by the caller; no hardware, runner or network service is needed.

```js
// assay-docs: runnable
import {
  createAssessmentDefinition,
  createEvidenceBundle,
  evaluate,
  projectPublicResult,
} from "@0xbuff/assay";

const definition = createAssessmentDefinition({
  schemaVersion: 4,
  assessmentId: "calibration",
  revision: "rev1",
  policyVersion: "composed-required-v1",
  criteria: [
    {
      id: "voltage",
      kind: "number_range",
      mode: "required",
      visibility: "public",
      parameters: {
        expected: {
          type: "literal",
          value: { min: 98, max: 102, minInclusive: true, maxInclusive: true },
        },
        unit: "mV",
      },
    },
  ],
  composition: {
    rootGroupId: "root",
    groups: [
      {
        id: "root",
        operator: "all",
        children: [{ kind: "criterion", id: "voltage" }],
      },
    ],
  },
});
if (!definition.ok) throw new Error("Invalid definition");

const evidence = createEvidenceBundle(definition.value, {
  schemaVersion: 4,
  observations: [
    {
      criterionId: "voltage",
      evidenceRef: "measurement",
      kind: "number",
      completeness: "complete",
      value: 101,
      unit: "mV",
    },
  ],
});
if (!evidence.ok) throw new Error("Invalid evidence");

const result = evaluate(definition.value, evidence.value);
const view = projectPublicResult(definition.value, result);
if (!view.ok) throw new Error("Projection rejected");
if (view.value.outcome !== "pass") throw new Error("Expected pass");
console.log(view.value.outcome);
```

Run:

```sh
node calibration.mjs
```

Expected output:

```text
pass
```


## Change the measurement

Change the observation's `value` from 101 to 103 and remove the assertion that requires a pass. The output becomes `fail`.

Restore the value and replace the observation array with an empty array. The outcome becomes `inconclusive`: there is no measurement to compare.

If you change the unit from `mV` to `V`, evidence creation fails. Assay does not convert units.

## What happened

`createAssessmentDefinition` validates and seals the criteria. `createEvidenceBundle` binds the observation to that definition. `evaluate` verifies both records and compares the measurement. `projectPublicResult` constructs the limited result used in the example.

The full evaluation record is for your application's private use. See [public results](/docs/assay/public-results) before returning findings from a service.

Continue with [criteria](/docs/assay/criteria) and [composition](/docs/assay/composition) to evaluate other kinds of results.
