## Requirements

- **Node.js 24 or newer** for the supported Node execution environment.
- A modern **ESM** project. TypeScript declarations ship with the package.
- **React 19 and React DOM 19** only if you use the React player. They are optional peer dependencies; the compiler does not load React.

## 1. Install the library

~~~sh
npm install @0xbuff/throughline
~~~

With pnpm:

~~~sh
pnpm add @0xbuff/throughline
~~~

For React applications, also install the compatible peers if they are not already present:

~~~sh
npm install react@^19 react-dom@^19
~~~

These examples target package version `0.0.2`. To reproduce the documented behavior exactly, pin the package version and commit your lockfile:

~~~sh
npm install @0xbuff/throughline@0.0.2
~~~

## 2. Compile a trace

Make `counter.mjs` in a Node ESM project:

~~~js
import { compile } from "@0xbuff/throughline";

const source = [
  "```thl flow",
  'node counter "Counter" = 0',
  'step "Increment"',
  "  set counter = 1",
  '  note "Counter is one."',
  'step "Increment again"',
  "  set counter = 2",
  "```",
].join("\n");

const trace = compile(source);

for (const frame of trace.frames) {
  const counter = frame.state.entities.find((entity) => entity.id === "counter");
  console.log(frame.index, frame.label, counter?.value);
}
~~~

Run it:

~~~sh
node counter.mjs
~~~

Expected output:

~~~text
0 Initial state 0
1 Increment 1
2 Increment again 2
~~~

Every `step` creates a new frame, so `frames.length` is the number of steps **plus one**. Frame zero always represents the initial state.

## 3. Render in React (optional)

Create a component:

~~~tsx
import { useMemo } from "react";
import { compile } from "@0xbuff/throughline";
import { ThroughlinePlayer } from "@0xbuff/throughline/react";
import "@0xbuff/throughline/styles/throughline.css";

const source = [
  "```thl flow",
  'node counter "Counter" = 0',
  'step "Increment"',
  "  set counter = 1",
  '  note "The value changed."',
  "```",
].join("\n");

export function CounterPlayer() {
  const trace = useMemo(() => compile(source), []);
  return <ThroughlinePlayer trace={trace} theme="auto" />;
}
~~~

Import the CSS **once** in your application, preferably in its root stylesheet or entry point. The player supplies the SVG scene, timeline, stepping controls, captions, and an expandable state inspector. It starts paused at frame zero.

When the trace changes identity, the player resets its position and playback speed. Avoid recompiling on every render: move constant traces out of the component or memoize them.

Learn about [player options, keyboard shortcuts, accessibility, and CSS themes](/docs/throughline/react-player).

## 4. Explore the included examples

~~~ts
import { EXAMPLES } from "@0xbuff/throughline/examples";
import { compile } from "@0xbuff/throughline";

for (const example of EXAMPLES) {
  const trace = compile(example.source);
  console.log(example.id, example.title, trace.frames.length);
}
~~~

The built-in fixtures include **Reconciliation**, **Shared references**, and **Matrix multiplication**. They are real input sources, not synthetic mock traces.
