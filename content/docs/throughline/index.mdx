Throughline is a small TypeScript library for explaining **how state changes over time**. Write named steps in a `thl` block, compile them into a predictable sequence of snapshots, and—if you use React—show those snapshots in an accessible, interactive player.

It is suited to educational diagrams, algorithms, reference semantics, recursion, binary arithmetic, matrix multiplication, protocols, and workflow walkthroughs. It is **not** an interpreter for arbitrary code, an automatic tracer of a running program, or a video renderer.

## The smallest useful trace

The following `flow` trace describes a counter that changes from zero to one:

~~~md
```thl flow
node counter "Counter" = 0
step "Increment"
  set counter = 1
  focus counter
  note "The counter now holds one."
```
~~~

~~~ts
import { compile } from "@0xbuff/throughline";

const source = [
  "```thl flow",
  'node counter "Counter" = 0',
  'step "Increment"',
  '  set counter = 1',
  '  focus counter',
  '  note "The counter now holds one."',
  "```",
].join("\n");

const trace = compile(source);

console.log(trace.version); // 1 — schema, not npm release
console.log(trace.frames.length); // 2 — initial state + one step
console.log(trace.frames[1].state.entities[0].value); // 1
~~~

Compilation produces all snapshots up front; moving backward or forward through frames does **not** rerun the source.

## Choose a domain

| Domain | Use it when you need to explain | Input |
| --- | --- | --- |
| [`flow`](/docs/throughline/flow) | State, data movement, systems, protocols, and workflows | Explicit nodes, links, and named steps |
| [`bindings`](/docs/throughline/bindings) | Variables, copies, object references, mutations, and rebinding | A restricted assignment and array-push language |
| [`binary`](/docs/throughline/binary) | Unsigned addition and carry propagation | Two binary operands |
| [`matrix`](/docs/throughline/matrix) | Matrix multiplication, cell by cell | Two compatible numeric grids |
| [`callstack`](/docs/throughline/callstack) | Factorial recursion, calls, and returns | One bounded factorial argument |

The computed domains generate the same trace model as hand-authored `flow`; they do not execute general-purpose source code.

## Ways to use Throughline

- **Compiler only:** import `@0xbuff/throughline` in Node.js 24+ or a compatible ESM environment. React is not needed.
- **React player:** render a compiled `Trace` with `@0xbuff/throughline/react` and opt-in stylesheet `@0xbuff/throughline/styles/throughline.css`.
- **Programmatic authoring:** construct a `Program` or use `tracer()` to narrate a deterministic computation in TypeScript.
- **Examples:** import the read-only sample set from `@0xbuff/throughline/examples`.

Only these four import paths are part of the supported package surface. [API reference](/docs/throughline/programmatic-api) · [React player](/docs/throughline/react-player) · [Recipes](/docs/throughline/recipes)
