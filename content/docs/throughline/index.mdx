Throughline turns a short description of state changes into a sequence of frames you can inspect or play back. Write a `thl` block in Markdown, compile it with TypeScript, and optionally display it with the React player.

Use it to explain algorithms, data structures, recursion, and system workflows. Throughline **does not run the code being explained**; you describe the changes you want to show.

## Get started

Install the package:

~~~sh
npm install @0xbuff/throughline
~~~

Compile a trace:

~~~ts
import { compile } from "@0xbuff/throughline";

const trace = compile([
  "thl flow",
  'node counter "Counter" = 0',
  'step "Increment"',
  "  set counter = 1",
  '  note "Counter is now one."',
].join("\n"));

console.log(trace.frames.length); // 2: initial state and one step
~~~

This works without React or a network connection. To display the frames in a React application, use the optional `ThroughlinePlayer` and its stylesheet.

[Follow the complete setup](/docs/throughline/getting-started).

## Supported trace types

| Domain | What it shows |
| --- | --- |
| [Flow](/docs/throughline/flow) | Named nodes, links, and explicit state changes |
| [Bindings](/docs/throughline/bindings) | Variables, references, and shared mutations |
| [Binary](/docs/throughline/binary) | Unsigned binary addition, one bit at a time |
| [Matrix](/docs/throughline/matrix) | Matrix multiplication, one result cell at a time |
| [Call stack](/docs/throughline/callstack) | Factorial calls and returns |

All five produce the same `Trace` format. The compiler creates an initial frame and one frame per step; the player reads those frames without executing the source again.

## Version and support

These guides describe `@0xbuff/throughline` **v0.0.2**. The package is ESM-only, targets Node.js 24+, and offers an optional React 19 player. The trace format uses schema version `1`, which is separate from the package version.

See [compatibility](/docs/throughline/compatibility) for supported environments or [report a problem](https://github.com/0xbuffdev/throughline/issues) on GitHub.
