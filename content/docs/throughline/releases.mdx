## Current documented release

These pages target **`@0xbuff/throughline@0.0.2`**, published **November 8, 2026**.

~~~sh
npm install @0xbuff/throughline@0.0.2
~~~

The npm package is ESM-only, includes TypeScript declarations, and declares **Node.js 24 or newer** as its supported Node engine. The React player uses optional peers `react` and `react-dom` **19.x**; core compilation has no React requirement.

## Package version versus trace schema

| Version | Current value | Meaning |
| --- | --- | --- |
| npm package | `0.0.2` | Distribution, dependency upgrades, API/behavior changes |
| `Program.version` | `1` | Shape of the compiled/constructed authoring Program |
| `Trace.version` | `1` | Shape of the resulting frame and snapshot data |

The schema numbers are **not** an alias for the package version. A subsequent npm release may include behavior or styling changes without changing the trace schema. Because the package is still pre-1.0, pin versions and verify examples and output when upgrading.

### v0.0.1 — November 8, 2026

Initial public release with:

- Bounded deterministic Markdown-authored state-trace compilation.
- Version-1 Program/Trace structures and source-positioned diagnostics.
- Five domains: `flow`, `bindings`, `binary`, `matrix`, and `callstack`.
- Optional accessible React 19 player, state inspector, responsive layout, reduced-motion handling, and opt-in audio.
- Four explicit package entry points and Apache-2.0 licensing.

## Upgrading a consumer

1. Read the release notes and **pin** the package version when reproducibility matters.
2. Confirm your deployment environment satisfies the package’s Node engine and optional React peer constraints.
3. Import only the four public export paths; do not depend on internal layout, domain, or CSS file paths.
4. Compile every authored trace in tests/CI. Typecheck any source that uses `Program`, `Trace`, `Tracer`, or React props.
5. Verify frame counts, step labels, final state, and domain-specific behavior with representative examples.
6. Inspect player themes, CSS overrides, accessibility, and bundle output in actual browsers.
7. If you persist traces, check `Trace.version` when loading them. A version-1 schema number alone does not guarantee identical player behavior across npm releases.

## What is not in v0.0.2

There is no published custom-domain registration API, standalone SVG export, media/video export, runnable JavaScript interpreter, Vue/Svelte-specific player, controlled player step prop, or built-in learning account/grade system. Use the extensible public `tracer()` API to create a custom Program and its Trace without adding a new domain.
